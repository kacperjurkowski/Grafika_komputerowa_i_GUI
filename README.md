# Junctio

Symulator skrzyżowania: rysowanie dróg, znaków i sygnalizacji oraz symulacja ruchu z użyciem SUMO.
Projekt zaliczeniowy z przedmiotu Grafika Komputerowa i GUI.

## Uruchomienie

pip install -r requirements.txt
python main.py
